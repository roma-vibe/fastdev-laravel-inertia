# Changelog

## 1.0.0 — 2026-10-05

- Initial version: Laravel 13.34 with Inertia 3, TypeScript 6 and Vite 8; PHP 8.4+ on the host, PHP 8.5 in Docker.
- Choices at creation: Vue 3.5 or React 19; Tailwind CSS 4, Bootstrap 5.3 or plain CSS; SQLite, PostgreSQL 18 or MySQL 8.4.
- Pages use the same class names with every CSS option; one app.css per option defines them.
- Notes example through route, controller, form request, service, model, resource, migration and Inertia page, with PHPUnit feature tests.
- composer check runs Pint, Larastan (level max), PHPUnit, ESLint, Prettier and the TypeScript compiler with zero warnings.
- Docker modes: no Docker, Docker to run the app (FrankenPHP production image), everything in Docker (default, dev container with hot reload); data in a volume or the project folder.
- FORWARD_DB_PORT (the database container's port on this machine) is allocated only for PostgreSQL and MySQL.
- .env keeps Laravel's MAIL_FROM_NAME and VITE_APP_NAME that reference APP_NAME.
- npm lockfiles per frontend and CSS combination and composer.lock are generated by scripts/lockfiles.mjs.
- Verified: all five selections; No Docker (SQLite) and Docker to run the app (PostgreSQL) ran with PHP, Composer and Node.js stand-ins in Docker, not a native PHP on macOS.
- Not verified: PostgreSQL or MySQL without Docker (own server), and running the production container with MySQL (its image is built).
- AGENTS.md and .env.example note that Vite expands $VAR in .env values even in single quotes, so VITE_APP_NAME may differ from APP_NAME; pages use the appName prop.
